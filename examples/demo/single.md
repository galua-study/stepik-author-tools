## Task 1.1.1. Read a value

**Type:** single choice

### Condition

Which expression produces an integer?

### Options

1. `4`
2. `"4"`
3. `[4]`

### Correct answer

1. `4`

### Explanation

Quotes create a string; square brackets create a list.
