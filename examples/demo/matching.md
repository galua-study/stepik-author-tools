## Task 1.1.3. Match values and types

**Type:** matching

### Condition

Match each value to its Python type.

### Left column

1. `7`
2. `"seven"`
3. `[7]`

### Right column

- **A** — `list`
- **B** — `int`
- **C** — `str`

### Correct answer

1 — B, 2 — C, 3 — A

### Explanation

Container type is independent of the type of its elements.
